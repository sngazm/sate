# プライベートファイル

人に見せたくない内容を検索・一覧から隠す指定。実装は `src/components/FileHeader.tsx`（チェックボックス）、
`src/hooks/useFile.ts`（`updatePrivate`）、`src/lib/db.ts`（除外ロジック）。

- ファイルヘッダー右上の "Private" チェックボックスで切り替え
- フロントマターに `private: true` として保存
- ON のとき：
  - 全文検索インデックス（`search_index`）に登録しない → 検索でヒットしない
  - 一覧の本文プレビュー（`first_line`）を NULL にする → ファイルオーバーレイで内容が見えない
  - ファイルオーバーレイでは鍵アイコン付きで表示される

## 開くときの PIN・生体認証

ホットキーで Sate をすぐ出せるので、書きかけの Private な文章が間違って画面に出ないよう、開くときに PIN か生体認証（Touch ID）を
求められる。環境設定の「Private」の欄で「Private な文章を開くときに PIN コードを要求する」をオンにして PIN を決める（初期値はオフ）。
実装は `src/components/LockScreen.tsx`（ロック画面）、`src/App.tsx`（いつロックするか）、`src/lib/pin.ts`（PIN）、
`src-tauri/src/biometric.rs`（生体認証）。

間違って表示されるのを防ぐための機能で、盗み見を防ぐものではない。.md ファイルは暗号化せず、ほかのアプリでは普通に開ける。
PIN は今の PIN を知らなくても環境設定でいつでも変えられる（忘れて開けなくなるのを防ぐ）。

### いつロックするか

- Private な文章をファイルオーバーレイ（`Cmd+O`）から開いたとき
- Private な文章を表示したまま Sate を隠し、次に出したとき。隠し終えた（消える演出が最後まで流れた）時点でロックする。
  消える途中で出し直したときは、ずっと見えていたのでロックしない
- ロックしないとき：
  - 表示している文章の Private をオンにしたとき、PIN の要求を有効にしたとき（いま見ているので、隠すまではそのまま）
  - 一度開けた文章は、Sate を隠すまでは開き直してもロックしない

### ロック画面

- 本文・タイトル・余白メモ・ファイル名・文字数を見えなくし、中央に PIN の欄を出す。本文は裏に残したままなので、
  開けると Undo の履歴やキャレットはそのまま続く
- PIN の欄は 4 桁がちょうど収まる幅。4 桁そろったら確かめ、合えばそのまま開く（Enter は要らない）。違えば欄が揺れて空になる
- 生体認証がオン（「生体認証が可能な場合は使用する」。初期値はオン）で使える Mac なら、ロック画面が出るたびに
  macOS の Touch ID のダイアログを出す。キャンセルしたら PIN の欄に戻る。「Touch ID」のボタンで出し直せる
- ロック画面が出ているあいだも `Cmd+N`（新しい文章）、`Cmd+O`（ほかの文章）、`Cmd+,`（環境設定）は使える。
  `Cmd+F`（文書内検索）と Rewind は使えない
- Touch ID のダイアログは、開けたとき・Sate を隠したとき・ほかの文章に替えたときに閉じる
- Touch ID のダイアログはキー入力を取らないので、ダイアログが出たままでも PIN を打てる（打てばダイアログは閉じる）。
  `Esc` はダイアログを閉じる（環境設定の「Esc キーでも閉じる」がオンなら Sate ごと隠す）
- macOS の認証のダイアログ（coreautha）は Sate の画面（Status レベル）より上に出て、出ても Sate は前面のまま（実機で確認済み）。
  ダイアログのボタンをクリックすると coreautha が前面に来るが、ほかのアプリに切り替えたのではないので Sate は隠さない
  （`src-tauri/src/dive.rs` の `other_front_app`）。隠すと、ダイアログが取り消される → 前面が Sate に戻って出し直す →
  ロック画面がまたダイアログを出す、を繰り返してしまう

### PIN

- 数字 4 桁。数字以外は打っても入らない（全角の数字は半角として扱う）
- settings.json には PIN そのものではなく、ソルト付きのハッシュ（PBKDF2-SHA256）を置く（`privatePin`）。
  settings.json を開いたときに PIN が目に入らないようにするためで、総当たりには備えていない
- 環境設定の「確定」でその場で保存する。「確定」を押さずに「保存」したときも、欄に入れた PIN を使う
- 環境設定の PIN の欄も 4 桁の幅。PIN が決まっていれば欄に丸が 4 つ並び（placeholder）、決まっていなければ空。
  設定済みかどうかを言葉で書かない。「確定」すると欄が空に戻って丸が並ぶ
- PIN が決まっていなければ、PIN の要求はオンにできない

### 生体認証

- LocalAuthentication の `LAPolicyDeviceOwnerAuthenticationWithBiometrics`（指紋だけ。Mac のログインパスワードには回さない。
  代わりは Sate の PIN）
- 使えないとき（Touch ID が無い、指紋の登録が無い、失敗が続いてロックされた）はボタンを出さず、PIN だけで開く
