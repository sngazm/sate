# Sate の画面（Dive）

Sate の画面は一つだけで、ふだんは隠れている。呼び出すと、どのアプリを使っていても（そのアプリが全画面でも）
画面全体に重なって出て、背後がぼけて Sate だけになる。パッと切り替えられて、グッと没入できることを狙う。
コードと仕様書の中ではこの画面を「Dive」と呼ぶ（画面や環境設定には出さない）。
実装は `src-tauri/src/dive.rs` と `src/App.tsx`、出入りの演出は `src/lib/diveTransition.ts`。

## 挙動

- 出す：起動したとき、ホットキー、Dock のアイコンのクリック、`Cmd+Tab` などで Sate を選んだとき
- 隠す：ホットキー、`Esc`、`Cmd+W`、ほかのアプリを選んだとき（`Cmd+Tab` で選んだとき、Dock、別の画面のクリックなど）。
  IME 変換中の `Esc` は変換の取り消し。`Cmd+Tab` の切り替えの一覧を出しているあいだは隠さない
- 出すときは Sate を前面にし、隠すときは前に使っていたアプリを前面に戻す。消える演出の途中でも、
  クリックとキー入力はすぐ前のアプリへ戻る
- 隠すときは保留中のオートセーブを確定させる。隠しても Sate は終わらず、取り消し履歴やキャレット位置も残る
- ホットキーは環境設定でオンにしたときだけ使える（初期値はオフ）。オフのあいだはホットキーを登録しない。
  macOS のホットキーは他のアプリと同じキーでも登録が失敗しないので、勝手に登録すると他のアプリのショートカットや
  `⌥Space`（英字配列ではノーブレークスペースの入力）を黙って奪ってしまう。ホットキーの初期値は `⌥Space`
- マウスカーソルのある画面全体を覆う
- 出るときは「背後の画面がぼける → 塗りつぶされて何も見えなくなる → 本文がぼけた状態からピントが合って出る」を
  少しずつずらして重ね、消えるときはその逆順にする（それぞれ 1 秒。expo のイージングで、最初に大きく動いてゆっくり落ち着く）。
  途中で反対の操作をしても、その時点の見た目からつながる
  - 本文とタイトルのピントは、ぼけた影（`text-shadow`）とくっきりした文字の濃さを入れ替えて合わせる。
    `filter: blur` は小さい半径を指定しても一定以上ぼけて描かれ、外す瞬間にカチッと切り替わるので使わない
  - 本文のピントは 1.8 秒かけて合わせる（expo なので、0.6 秒ほどでぼけはほとんど見えなくなり、あとは余韻）
  - ピントが 9 割合うまではキャレットを隠す（キャレットは文字と違ってぼけない。合い切るまで待つと 2 秒以上見えない）
- 出るたびに、隠す前にフォーカスがあった所（はじめは本文）へフォーカスを戻し、本文ならキャレットも隠す前の位置へ置き直す。
  WebKit はウィンドウが前に出るとフォーカスを先頭の入力欄（タイトル）へ移し、さらにキー入力を受け取れるようになる前に
  本文へフォーカスしていると、受け取れるようになった時点でキャレットを先頭へ戻してしまう。そこでキー入力を受け取れるように
  なってから（ウィンドウの `focus`）戻す。クリックで前に出たときは、クリックした所を優先して何もしない

## 実装メモ

- ウィンドウは tauri.conf.json の `main`（隠れた状態・枠なし・透明で作る）を NSPanel に変換し（tauri-nspanel）、
  fullScreenAuxiliary + canJoinAllSpaces にする。ほかのアプリの全画面スペースの上にも出せる。
  Sate を前面にしても、そのスペースからデスクトップへ追い出されない（実機で確認済み）
- ウィンドウレベルは Status（25）。メニューバー（24）と常時表示の Dock（20）より上に出て、画面全体を覆う。
  IME の変換候補の窓はさらに上に出る（実機で確認済み）
- 出すとき・隠すときに前面にするアプリ：ほかのアプリが前面に来るたび（`NSWorkspaceDidActivateApplicationNotification`）と
  出す直前に、Sate 以外の前面のアプリを覚えておき、隠すときにそれを前面に戻す。分からないときは Sate が前面をやめて macOS に任せる
- Sate が前面に来たら（`NSApplicationDidBecomeActiveNotification`）出す。`Cmd+Tab` と、前面でないときの Dock のクリックはこれで出る。
  前面のときの Dock のクリックは `RunEvent::Reopen` で出す
- `Cmd+Tab` は macOS が受け取るのでアプリには届かない。ほかのアプリが前面に来た知らせを受けて隠す
- 起動時は、画面の JS が出し入れのイベントを聞けるようになって `dive_attach` を呼んだところで初めて出す
  （聞き始める前に送ったイベントは届かない）
- `Cmd+W` は、枠の無いパネルではメニューの「閉じる」（`performClose:`）が効かないので、画面の JS がキーを受けて `hide_dive` を呼ぶ。
  ウィンドウを閉じる要求が来ても、閉じずに隠す（閉じるとホットキーや Dock で出せなくなる）
- ホットキーは tauri-plugin-global-shortcut（Carbon の `RegisterEventHotKey`）。アクセシビリティ権限は不要。
  画面の JS が設定を読んだ時点で `set_hotkey` コマンドで登録する（オフなら外す）。設定画面でキーを記録している間は外す
- 背後のぼかしは非公開 API `CGSSetWindowBackgroundBlurRadius`（iTerm2 の背景ぼかしと同じ）。パネルを透明にして、
  画面の JS が毎コマ半径を変える。起動後に `dlsym` で探し、将来の macOS で無くなっていたらぼかさずに出し入れする
  （リンク時に結び付けると、無くなったときに Sate が起動しなくなる）。CSS の `backdrop-filter` はほかのアプリの画面をぼかせない。
  画面を撮ってぼかす方法は「画面収録」の許可が要るので使わない
- 隠れているあいだ（ほかのアプリを使っているときなど）WebKit は描くのを止めていて、出した最初の 1 コマが灰色になる。
  そこでパネルは透明（不透明度 0）のまま出し、画面の JS が 1 コマ描いたと知らせてきたら（`dive_ready`）見せる
- 消える演出のあいだもパネルは出したまま（クリックは素通しにする）。演出が終わったら（`dive_exit_done`）画面から外す
- Rust からのイベントは `getCurrentWebviewWindow().listen` で受ける
- tauri-nspanel が macOS の非公開 API を要するため `macOSPrivateApi: true`（Mac App Store には出せない）
